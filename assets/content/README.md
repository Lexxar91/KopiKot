# Учебный контент

Здесь находятся JSON-наборы учебного контента. Подключены `help.json` (справка),
`catalog.json` (21 товар и 3 цели) и `tasks.json` (6 заданий по 3 темам).
Загрузчики читают их из assets без сети. Тексты ситуаций и их параметры отделены
от Flutter-виджетов; общие подписи элементов форм остаются в UI.

Загрузчик каталога из `lib/data/content/` проверяет формат, версию, уникальные ID,
положительные целые цены, категории и диапазон эффектов. Неизменяемые определения
читаются из assets; дублировать их в Isar не требуется.
Прогресс игрока хранится отдельно от определений контента, чтобы обновление
формулировки задания не сбрасывало результат и не выдавало награду повторно.

Для каждого задания используются стабильный `id`, `title`, `topic`, `kind`,
`prompt`, параметры ситуации, `reward`, `success` и `retry`.
В текущем наборе все задания имеют `kind: choice`; правила и проверка ответов
находятся в актуальной реализации заданий. Данные не содержат исполняемый код.
Новое задание существующего типа добавляется данными; новый тип
взаимодействия может потребовать отдельного обработчика и виджета.

Минимум по ТЗ: 6 заданий по 3 темам, 8 покупок двух категорий, 3 цели,
9 различимых сочетаний внешности. У всех ссылок на товары и цели должны быть
существующие ID, у цен — положительные целые значения. Числовые условия задания
должны допускать решение; ошибочный выбор тоже получает понятное объяснение.

При добавлении материалов указывайте автора, источник и лицензию. Вместе с
контентом ведите [карту учебных ситуаций](../../docs/content_map.md).
