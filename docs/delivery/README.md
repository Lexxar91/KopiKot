## Повторная сборка

Из корня проекта:

```bash
python3 -B -m unittest discover -s tool -p 'test_export_delivery_docs.py' -v
python3 -B tool/export_delivery_docs.py
pdfinfo docs/delivery/companion.pdf
pdfinfo docs/delivery/presentation.pdf
```

Используются установленный Python 3, Google Chrome (либо Chromium) и системные
шрифты DejaVu Sans / Sans Mono. `pdfinfo` и `pdftotext` поставляются с Poppler
и нужны для проверки, а не сборки. В текущем Ubuntu эти инструменты уже есть;
пакеты Python и новые Flutter-зависимости не устанавливались.

Генератор `tool/export_delivery_docs.py` создаёт HTML и печатает его в PDF через
[Chrome Headless](https://developer.chrome.com/docs/chromium/headless).
Используется отдельный временный профиль, изображения встроены, внешние ресурсы
страницы не загружаются. Защита браузера не отключается. Рендерер поддерживает
заголовки, простые таблицы, абзацы, списки, ссылки, PNG и блоки кода из текущих
файлов; произвольный CommonMark не поддерживается.

Редактировать нужно Markdown и генератор, а не итоговые HTML/PDF. После правок
повторить экспорт, проверить число слайдов, извлечение текста и внешний вид
длинных таблиц. При другой версии Chrome/шрифтов переносы могут измениться;
побайтовая воспроизводимость PDF не гарантируется. Уведомления о шрифтах:
[DejaVu](../store/licenses/DejaVu_copyright.txt); шрифты встроенных снимков
описаны в [реестре графики](../assets.md).

## Что мешает финальной сдаче

Остаются физическая Android-приёмка и измерения, экспертная/пользовательская
проверка, окончательное имя пакета и ключ подписи, завершение сверки нативных
уведомлений (реестр Pub/Android уже [подготовлен](../third_party.md)),
решение команды о правах на собственные материалы, публичные
контакты и доступные экспертам ссылки. Сборка пока debug; релизный тег и видео
не подготовлены. Наличие этих PDF само по себе не закрывает требования сдачи.
